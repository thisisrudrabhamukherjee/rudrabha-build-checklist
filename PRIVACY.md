# Privacy notice

The authoritative copy of this notice is the one inside the application
(**Rudrabha Mukherjee's Build Checklist**, version **1.11.0**). This file is provided so the
notice can be read on GitHub without opening the app.

---

PRIVACY NOTICE

Rudrabha Mukherjee's Build Checklist, version 1.11.0
Created by Rudrabha Mukherjee

SHORT VERSION
This page collects nothing about you. There is no account, no sign in and no
tracking. Your work never leaves your device unless you choose to send it
somewhere yourself.

WHAT IS COLLECTED
Nothing. No name, no email, no phone number, no location, no usage figures,
no error reports, no advertising identifiers.

WHERE YOUR WORK IS KEPT
Inside your own browser, on this device only. Nobody else can read it,
including Rudrabha Mukherjee, and including whoever hosts the address you
opened it from. It is never uploaded.

NETWORK
Once open, this page sends none of your work anywhere and fetches nothing to
display itself. Exception: version check — on open it asks the address whether
a newer version exists; your browser may also check the worker file. That
request carries only your internet address and the time, as any web page
request does. Nothing you have written is part of it. You can switch the check
off in Settings. A file copy opened from disk makes no check.

HOW YOU GOT THIS PAGE
If somebody gave you this page as a file, nothing about you reached anybody
at any point.

If instead you opened it as a web page at an address, then your device asked
that website for the page, exactly as it would for any website. The company
hosting that address will have recorded your internet address and the time,
as nearly all websites do, and their privacy rules cover that record, not
this notice. That happens once, when the page loads. None of your work is
sent. If you would rather nobody saw even that, save the page as a file and
open the file instead.

COOKIES AND TRACKING
None. There are no cookies, no pixels, no analytics and no advertising.

WHEN YOUR WORK DOES LEAVE THIS DEVICE
Only when you press a button to make that happen: Copy puts words on your
clipboard, and Save puts a file in your downloads folder. When you then paste
those words into an AI assistant, that company's own privacy rules apply, not
this page's. Read theirs before sending anything private.

LOCK
If you turn on the lock, your work is scrambled on this device with a key made
from your PIN. Nobody, including Rudrabha Mukherjee, can unscramble it without
your PIN (or your recovery answer, if you chose to set one).

CHILDREN
This page collects nothing, so it collects nothing about children either.

DELETING YOUR WORK
Open Progress and press "Clear everything and start again". Clearing your
browser data also removes it. There is no copy anywhere else to delete.
